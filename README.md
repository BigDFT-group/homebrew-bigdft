# BigDFT Homebrew Tap

This is a Homebrew tap for [BigDFT](http://bigdft.org), an electronic structure calculation package based on Daubechies wavelets.

Install BigDFT using pre-compiled bottles:
```bash
brew tap BigDFT-group/bigdft
brew install bigdft
```

If you prefer to compile from source or if bottles aren't available for your system:
```bash
brew tap BigDFT-group/bigdft
brew install --build-from-source bigdft
```

To update to the latest version:
```bash
brew update
brew upgrade bigdft
```

To remove BigDFT:
```bash
brew uninstall bigdft
```

To also remove the tap:
```bash
brew untap BigDFT-group/bigdft
```
